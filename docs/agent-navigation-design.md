# Agent 查看与定位设计

状态：Swift 产品界面已实现。定位路径回退后，用户确认复用原窗口并进入原有目标。验收范围见文末；视觉规范见 [ui.md](ui.md)。HTML 只作交互参考。

目标：看到需要关注的状态后，打开面板即可辨认 agent，再点一次定位。不把查看状态、选择目标、跳转和 seen 混成一个动作。

## 范围

首版设计包含：

- `Activity` 平铺快速列表：按blocked → done → working → 最近三个idle及状态时间排列。idle的“最近”按Herdr状态更新时间，不按定位历史。各等级不另设分组标题或折叠区。
- `Sources` 结构化浏览，保留来源、Session、Space/worktree 和精确定位。两个入口各有裸小图标，离线提示说明为 `1 offline`。
- 面板内键盘选择、Enter、Escape；可配置的全局呼出入口。
- 跳转中与失败反馈、按身份稳定选择、状态刷新不挪动列表。

本轮不纳入通知、搜索、收藏、自动跳转、下一条自动处理、独立未读队列或“标记处理完成”。全局快捷键不预占系统组合，由 Settings 录制。原型用外部按钮模拟快捷键呼出，不注册系统热键。

经用户确认，全局呼出采用 [KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts)：复用录制控件、存储与系统/菜单冲突提示，不自写全局监听。默认组合为空，key-up 执行面板开关；注销 handler 保留用户组合。应用包需携带该依赖的资源 bundle 与许可证。

## 主面板

```text
菜单栏：状态图标与数量，整体是一个开关入口

┌ [ ≋ Activity | ▤ Sources ]          ⚠︎ 1 offline ┐
│ ! 评估报告                           Needs input │
│   assessment                                     │
│ ✓ 评估报告                           Completed   │
│   kvm / dev / assessment/review                   │
│ ✓ herdling                           Completed   │
│   herdling                                       │
│ ▶ review                                         │
│   assessment                                     │
│ ○ tools                                          │
│   tools                                          │
└──────────────────────────────────────────────────┘
```

示意中的边框不是新增容器。仍只有一个面板表面，没有底栏、卡片底板或分组玻璃。应用继续使用英文标签；本页用中文说明行为。

### Activity

- 每次重新打开面板都进入此视图；不恢复成上次留下的折叠目录。列表先呈现需关注项，再呈现运行中和最近空闲的目标。
- 候选要求在线来源与在线Session，blocked／done优先，随后working及最近idle；idle只取全来源合计最新三个，unknown与离线目标不入列。同等级按状态更新时间由新到旧排列，平局保留快照顺序；打开后暂时掉线的目标原位显示Unavailable，不能定位。
- 不折叠、不嵌套工作区。整行只表示一个 agent，点击行内任何文字都定位同一个目标。
- 第二行通常只显示工作区，隐藏本机来源名和 default；远程或非默认 Session 补充对应身份，同工作区内同名 agent 补 pane ID。完整身份进入帮助和可访问性描述。
- 最近 idle 不要求曾经通过 Herdling 定位；它反映状态时间，不证明用户看过或处理过内容。pane 退出或来源身份失效后不复活成同名目标。
- 没有任何候选时只显示一行次级空态提示；浏览目录复用顶栏 `Sources`。只有一个可定位项时也显示它，不自动跳转。
- 各等级共用平铺目标行，不显示分组标题、重复数量或右侧working、ready；常规状态由左侧图标表达，帮助与辅助功能读出真实状态。保留Needs input、Completed、Opening、Unavailable、Retry。未出现在名单中的失败目标单列为Last jump。
- 来源离线不等于“无事可做”。顶栏网络图标与数量提示不可用来源，详情进入 help/辅助功能；全部离线且没有目标时保留明确空态。新开快速名单跳过不可定位目标；打开中失效的行仍原位提示。全部视图保留离线缓存供检查。

### Sources

- 保留现有结构和顺序、层级缩进、单 Main 工作区省略、远端离线提示。
- 来源／工作区摘要最多展示优先级最高的两种状态；完整计数保留在 help 和辅助功能中。先保标题，再压缩分支副标，不改变面板宽度或行高。
- 来源标题带手风琴箭头，最多展开一个，也允许全部收起。保留有效已保存来源；空偏好保持全收起，失效偏好回退到第一个来源。点当前来源收起，点其他来源关闭前一个并展开该项。可定位工作区显示定位语义，不伪装成折叠控件；纯 Space 标签不成为隐形按钮。
- agent、工作区、Session 各自定位各自的对象，不以第一个 agent 代替工作区目标。
- 来源展开偏好独立保留；切回此视图可以继续浏览，不影响下一次打开面板默认进入 Activity。

## 行为契约

| 操作 | 对象与结果 | 不发生的事 |
| --- | --- | --- |
| 左键菜单栏 | 开启或关闭同一面板 | 不按候选数量改为跳转 |
| 全局呼出快捷键 | 同一开关动作；键盘打开时按快速列表顺序选首个有效项，最后是失败恢复入口 | 不直接发送 focus |
| Activity / Sources 视图切换 | 切换浏览视图 | 不改变终端焦点或 seen |
| 来源标题或手风琴箭头 | 切换该来源折叠，展开时关闭前一个 | 不跳到来源的第一个 agent |
| 鼠标悬停 | 显示行反馈 | 不选定终端、不清 seen |
| 上下键 | 移动界面选择，按目标身份绑定 | 不跳转、不因刷新换成同索引的另一行 |
| Enter / 单击 agent | 提交对该 pane 的定位请求 | 不替换成名称相同的另一个目标 |
| Enter / 单击工作区入口 | 提交该工作区定位请求 | 不附带选择某个 agent |
| Escape / 外部点击 | 关闭面板；未提交定位时留在原工作位置 | 不回滚已经提交的定位请求 |
| 右键菜单栏 | Refresh、Settings、Quit | 不增加常驻底栏 |

鼠标打开时不默认选中一行；首次向下键选择第一条有效项。没有有效项时 Enter 不执行任何定位。名单只保留一个强调色高亮，由最后一次真实鼠标移动或键盘操作接管；鼠标移到另一可用行后，Enter 对应该行。静止指针下的滚动、布局和状态刷新不抢走键盘选择；悬停本身不提交定位或 seen。

全部视图中，上下键遍历可操作项；来源上的 Enter 切换折叠，左右键收起或展开；子项的左方向键返回父层，不承担定位。Tab 保持控件间的正常焦点移动。

## 实时更新与稳定性

面板关闭时可以自由重算分类与排序。打开期间：

1. 固定已展示的成员和顺序；状态、在线性与可定位性继续更新，不改变选择身份或Sources层级。
2. 新出现的候选留到重新打开再展示，不插到鼠标或选择光标下面。空快照有新目标时提示重新打开。
3. 原项变成 working、idle 或消失时，原位显示最新状态或不可用，不继续声称它完成或可定位。暂留行不是新的未读记录。
4. 删除 Update list 控件；重新打开才重建名单。鼠标打开清空选择，键盘打开预选首个有效项，均不直接执行定位。
5. 在线状态改变会立即阻止不合法定位，不为了保持布局而继续使用旧目标。

名单顺序与最近三个 idle 来自本次浏览快照；快速列表不重复显示分组标题或数量。新 blocked、done、working 或 idle 到达空快照时提示重新打开，不悄悄冻结整个数据源。

## 定位反馈与 seen 边界

```text
浏览 / 选择 → 提交明确目标 → 正在定位
                            ├ 成功：关闭面板，目标客户端到前台
                            └ 失败：保留目标与原因，可重试
```

- 目标身份至少包含 source、session、pane；工作区使用 workspace ID。标题只用于显示。
- 同一目标重复点击不重复启动；更换目标沿用 latest-request 规则，过时结果不得关闭面板或覆盖最新错误。
- 失败反馈必须能指回原目标。即使该 agent 的后端状态已变化，也不能把错误和重试机会一起隐藏。
- 当前名单内的失败优先原位显示，不改变行高。关闭后重新打开仍有失败记录时，单独提供上次目标的恢复入口；它不计入 Attention 数量，也不冒充仍处于 done 的 agent。
- 只在 Herdr 定位调用与终端客户端激活都返回成功后，报告定位动作完成。命令返回成功不是用户实际看见、读懂或处理结果的证据。
- 不在打开面板、渲染列表、切换视图、鼠标悬停或键盘选中时发出 focus/seen 请求。
- Herdling 不自行把 `done` 改成 `idle`，也不通过删除一行模拟“处理完成”。状态变化由 Herdr 回报。

### 当前集成的限制

本次只读检查中，CLI 为 Herdr 0.9.3，实际 daemon 为 0.9.0：`herdr status server` 回报 0.9.0，运行进程映射到 Homebrew 0.9.0 路径。下述结论按实际 daemon 的 v0.9.0 源码；远端来源仍需单独核对。

- `done` 是 idle lifecycle 与 unseen 的组合。seen 与 lifecycle 是两回事。
- workspace、tab、pane、agent focus 都可能通过切换 tab 或显式调用将目标 tab 内所有 pane 标为 seen（`seen = true`），同时清掉多个 done 提示。这不代表用户逐条处理过它们。
- 公共 workspace/tab/pane focus 会向同一 Session 的所有 shell clients 投射工作区和 tab 位置，并非只改变被拉到前台的终端 client。pane 焦点也是 tab 共享状态。
- 当前 Herdling 的 `tab.focus` 加 `agent.focus` 组合在 tab ID 有效时可以完成 tab 投射与共享 pane 定位；不能把整个现有流程判为无效。但没有 tab ID 时只执行 `agent.focus`，没有同等的客户端投射保证。
- 当前 Herdr focus 与终端激活并行执行。若一半失败，另一半可能已经改变焦点或 seen；超时也不证明服务端未执行。

因此，不能承诺“只清目标 agent 的已读”“只影响一个 Herdr client”“失败完全无副作用”。首版遵循 Herdr 的状态与定位语义，不新增本地未读模型来掩盖它们。原型把后端状态回报做成独立事件，用来演示跳转未成功但状态已经变化的情形。

用户报告原生版本出现额外打开及同名空 Space。有 tab ID 的 agent 恢复改动前的 `tab.focus → agent.focus`，不把界面重排与定位协议迁移捆绑。仅无 tab ID 时使用公共 NDJSON `pane.focus` 补齐定位。回退后用户确认复用原窗口、进入原有目标；底层为何发生额外打开尚未独立复现，不能把服务端 snapshot 正确当成客户端验收。

## 尺寸与可访问性

- 保留420pt宽，外框向原生右键菜单的12pt圆角对齐；顶栏与名单共用6pt水平内缩，名单背景宽408pt，底部同留6pt。内容边界与普通行四角均6pt，不另把顶栏做成更圆的控件。4pt overlay滚动条与名单边界隔1pt，保留原生命中与滚动语义；不加永久单边槽。正文与状态语义保留，面板离线／错误使用独立亮暗warning墨色，Settings装饰色不跟随；裸图标保留列表14pt Regular／导航14pt Medium角色。现行视觉规范及原生测量与适配范围见[ui.md](ui.md)。
- 快速列表第二行显示身份，使用 40pt 行高；它换掉的是寻找和展开层级的动作。四个等级不折叠，共用2pt行间距。全部视图仍用 38pt 来源标题、32pt 内容行、4pt 顶层间隔与现有内部间距。
- 视图切换保留38pt点击区、居中28pt表面和独立14pt图标槽，四角与菜单高亮同为6pt。顶部点击区留1pt，按钮组不额外内收；底块上、左到外壳都留6pt，与名单背景对齐。12pt Regular不变，水平内缩10pt、图文布局间距10pt补偿导航与名单的槽位差，图标中心在23pt，未缩进标题从40pt开始；离线尾列与名单尾部内容区同距右边12pt，读数继续保留各自的箭头或chevron槽位。current仅用文字与图标明暗区分，来源展开仅用箭头和内容表达，两者不常驻铺底；导航hover与名单可用行的hover／键盘选择统一用强调色底、白色文字与图标；按下和原生focus保留plain Button反馈。不可用定位项不显示强调色，键盘检查保留中性底色与状态原因。状态研究与历史实测见[交互状态审计](interaction-state-audit.md)。
- 视图切换与离线提示共用顶部一行；不增加底部工具栏，不叠玻璃，也不新增列表更新按钮。
- 焦点可见，选择变化滚动到可见范围；完整名称和定位对象向 VoiceOver 暴露。状态含义不只靠颜色。
- HTML 原型只验证信息布局和交互语义，不证明原生玻璃、字体光栅化、焦点环或系统快捷键行为。

## 原型检查

入口：[交互原型](prototypes/agent-navigation/index.html)。使用模拟数据，不连接 Herdr、SSH 或真实终端。

HTML 是早期设计记录，仍演示成功定位历史；不代表当前四等级名单。All agents 在原型中简化为来源→工作区→agent，用于检验选择与定位的区别；产品仍保留现有 Session / Space / worktree 层级，不以原型替换它们。

| 场景 | 必须成立 |
| --- | --- |
| 零、一、多条待关注 | 打开动作一致，均不自动定位 |
| 跨来源同名 agent | 行内可辨认身份，导航结果保留精确目标 |
| 悬停、切视图、上下选择 | 模拟终端位置不变，不生成 seen 操作 |
| Enter / 单击 | 只有所指目标进入 pending；成功才关闭面板 |
| 定位失败、重试 | 错误指向同一目标，重试不变成相邻项 |
| 同 tab 两条 done，后端先清 seen、终端激活后失败 | 状态可一起变 idle，但失败目标仍可重试，不能宣称两条已处理 |
| 列表打开后状态变化 | 原位更新状态，不重排；重新打开后使用最新快照 |
| 目标离线或消失 | 立即禁止定位，不能报成功 |
| 完成提示清除后再打开 | 近期成功定位行仍可直接回去，不需重走目录 |
| 关闭后重新打开 | 进入最新 Need attention 名单，不继承旧折叠入口 |

原型结果用于收敛设计，不代替产品的行为测试和真实终端验收。

- 图标统一版本：159 tests / 12 suites 串行通过，release、签名和 diff 检查通过。模板基底符号避免按钮隐式填充；来源中性色不替换状态和告警色。实拍检查 Activity、来源收起／展开、导航和离线来源悬停；稳定面板高度138／1197／138pt，保留原展开偏好，未触发真实定位。

## 实现切口

- `SessionStore` 继续持有来源与 agent 的真实状态。浏览快照只存有序身份，不复制一份会滞后的状态模型；提交跳转前再按身份解析最新位置和在线性。
- Activity 的浏览状态负责模式、四等级有序身份与选择；最近 idle 直接按在线状态时间选取，不消费定位历史。Sources 复用现有层级，避免顺手重写已验证的来源顺序、工作区判定与远端包装。
- agent 与工作区使用不同的定位目标类型；行文案、键盘动作和适配器调用由同一目标决定，不能各自根据标题猜测。
- 继续复用 `RowSymbol`、`RowSlot`、行反馈和 pending 机制。带副标题的快速行新增明确尺寸，不全局拉高普通内容行。
- 顶部切换行参与真实高度测量；整个内容边界统一裁切。不恢复旧底栏的固定高度预留，不分别给切换行和列表套玻璃。窗口与折叠继续共用原有动画时钟。
- 首批产品测试先钉住：浏览零 focus、零/一/多候选行为一致、同名目标身份、更新中选择稳定、离线阻止定位、过时导航结果无效。随后验证实际客户端的工作区、tab、pane，而不只验进程被激活。
