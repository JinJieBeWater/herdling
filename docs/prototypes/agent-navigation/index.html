操作语义与真实 focus 限制

菜单栏入口在 0 / 1 / 多个 agent 时都只开关面板。Quick access 包含 Needs attention（Herdr 回报 blocked 或 done）与 Recent jumps（最近三个成功跳转的 agent / pane，与当前需关注项去重）。都不是已读或处理记录，历史不从 idle 列表凑，也不持久化。

实际 daemon 0.9.0 / CLI 0.9.3：真实 focus 可能把目标 tab 所有 pane 标为 seen（true），同时清掉多个 done 提示；workspace / tab / pane focus 可能影响同 session 多个 shell client。失败也不能承诺零副作用，本原型不执行这些真实操作。

    All agents：来源标题只折叠；工作区行提交工作区目标；agent 行提交精确 pane。↑ / ↓ 选择可操作行，不导航。跨视图或更新名单按稳定 ID 保留可见选择，不按位置替换。这里简化为来源→工作区→agent 样本；产品保留现有 Session / Space / worktree 层级。

    原型限制：真实客户端焦点投射与失败副作用未在 HTML 中验证。seen 变化不代表用户读懂或处理完结果；这里没有“标为已读”或“处理完成”动作，也不因导航自行改变 done。真实操作的验收边界交由产品规范确认。
